
ML Regression Trainer
A beginner-friendly Python tool for training and evaluating regression models using scikit-learn. Supports Linear, SVM , Decision tree and Random Forest regressions. Ideal for students, data science enthusiasts, and anyone learning machine learning fundamentals.

🚀 Features
- Train multiple regression models with a single command
- Evaluate model performance using metrics like  R²
- Visualize predictions vs. actual values
